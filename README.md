# 徐徐002 · 微信公众号推送

一套「让智能体替你写、排、推公众号」的最小工具包。

不需要会写代码。装两个智能体，把这个仓库地址丢给它，剩下的它会带着你做。

---

## 你需要什么

- 一台电脑（Windows 或 Mac 都行）
- 能正常上网（手机热点也行）
- 半小时
- 一个公众号（个人订阅号就行）

---

## 五步走

### 第一步：装两个智能体

1. 打开 **qoder.com/zh/download**，下载对应系统的版本（Windows 或 Mac），安装后手机号登录。
2. 打开 **workbuddy.cn**，同样下载对应系统的版本，安装、登录。
3. 两个都装好，桌面上会有两个图标。哪个都行，下面以 Qoder 为例。

### 第二步：把仓库丢给它

打开 Qoder，新建对话，把 `prompts/01-搭环境.md` 整段复制进去（记得把仓库地址换成这个页面的地址）。

它会自己下载、安装、报错、重试。你要做的是：看着，遇到弹窗点允许，它问你就答。

网络不稳的，先挂好梯子或开热点再开始。装环境这一步最吃网速。

### 第三步：准备公众号

把 `prompts/02-准备公众号.md` 发给它，跟着一步一步点。

卡住了，就把报错截图发给它。

### 第四步：写第一篇

把 `prompts/03-写稿排版.md` 发给它，把你和 AI 的对话贴在后面。

配图和封面用 `prompts/04-封面配图.md`。（本地部署生图模型或配置 API，看我的相关文章或视频号，暂未发布。）

### 第五步：推草稿

把 `prompts/05-推草稿.md` 发给它。推完它会回读核对。

群发键自己按。

---

## 文件说明

```
scripts/build.py     把 content.json 变成公众号能用的 article.html
scripts/check.py     推送前自检：图在不在、封面尺寸对不对、凭据有没有
scripts/publish.mjs  上传图片 + 建草稿 + 回读
content.example.json 文章内容示例（段落、小标题、图、代码块）
config.example.json  配置示例（封面路径等）
prompts/             五段可以直接复制的提示词
assets/              你的配图放这里
```

## 常用命令

```bash
npm install                     # 装依赖（只需一次）
python scripts/build.py         # 生成 article.html
python scripts/check.py         # 自检
node scripts/publish.mjs        # 推草稿（会打印草稿 ID）
```

## 常见报错

| 报错 | 原因 | 怎么办 |
|---|---|---|
| `40164` | 本机 IP 不在白名单 | 公众号后台「设置与开发 → 基本配置」加上当前公网 IP |
| `40001` | token 被别的进程顶掉 | 不要同时跑两个推送脚本；删掉本地 token 缓存再试 |
| `45009` | 接口调用超限 | 等一会儿再推，别连点 |
| 图在草稿里是灰的 | 图片没走自己的接口上传 | 正文图用 `media/uploadimg`，封面用 `material/add_material` |
| 封面被裁掉一块 | 先裁后缩 | 按 2.35:1 和 1:1 直接生成，只做等比缩放 |
| 正文出现 `title:` 字样 | 头部没闭合 | 检查 frontmatter 是否以 `---` 结尾 |

## 三条安全提醒

1. **AppSecret 只存在自己电脑的 `.env` 里**，不要发群、不要截图。
2. 提示词里写了「不要调用付费接口」，别让智能体替你开通任何付费服务。
3. 推送只到草稿箱，群发是不可撤回动作，永远自己按。
